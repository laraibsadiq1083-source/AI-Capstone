# Prompts Used

## Prompt 1

Create a simple Task Manager React application.

Requirements:
- Add a title "Task Manager".
- Allow users to add new tasks.
- Display tasks in a list.
- Add a button to mark tasks as completed.
- Add a button to delete tasks.
- Completed tasks should appear with a line through the text.
- Keep the UI clean and responsive.
- Use React functional components and hooks.
- Organize the code clearly
I used Cursor AI as a development assistant to generate the initial React Task Manager application. AI helped create the React components, implement task management features such as adding, completing, and deleting tasks, and organize the project structure. This reduced development time and helped me focus on testing and understanding the code.
After AI generated the code, I manually reviewed and tested the application. I verified that tasks could be added, marked as completed, and deleted correctly. I also checked the layout and ensured the application worked without errors before submitting.
