# Project Rules

1. Every settings form must validate all required fields before submission.

2. Every input field must have an accessible label.

3. Password fields must require a minimum of 8 characters.

4. Review all AI-generated code before accepting changes.

5. New features should be organized into reusable components whenever possible.

6. Verify functionality after implementation before considering the task complete.
